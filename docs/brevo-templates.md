_Generated by `bun run docs:brevo` from src/emails/template-ids.ts and template-catalog.ts. Do not edit by hand._

## Numbering scheme

Each category owns a contiguous block of Brevo IDs:

```text
template id = category base + language offset
category fallback = category base + 9
```

| Language            | Offset |
| ------------------- | ------ |
| nl                  | +0     |
| en                  | +1     |
| fr                  | +2     |
| de                  | +3     |
| es                  | +4     |
| it                  | +5     |
| pt                  | +6     |
| pl                  | +7     |
| zh                  | +8     |
| _category fallback_ | +9     |

## Delivery cascade

1. Target template — category base + language offset
2. Category fallback — category base + 9
3. Global fallback — #21
4. Inline HTML rendered by ROUT itself

Every downgrade triggers the admin alert template #11.
